# 🔐 Sistema de Gestión de Escape Rooms para Stands y Eventos (v5.1)

Aplicación móvil multiplataforma desarrollada en **Flutter** con backend en **Supabase (PostgreSQL)** e integración de **Inteligencia Artificial (Google Gemini API)**. Diseñada para digitalizar, administrar y ejecutar experiencias de Escape Room interactivas en ferias, exposiciones y eventos presenciales de alta concurrencia.

---

## 📱 1. Instalación Rápida en Android (Vía APK)

Si sos **jugador**, **organizador de stand** o **evaluador** y querés instalar la aplicación directamente en tu teléfono Android sin compilar código:

1. Dirigite a la sección **[Releases](../../releases)** de este repositorio (en la columna derecha de la página principal de GitHub).
2. Buscá la última versión publicada (**`v5.1.0`** o superior).
3. En el desplegable **Assets**, descargá el archivo **`app-release.apk`** en tu celular.
4. Abrí el archivo descargado. Si tu navegador o gestor de archivos te lo solicita, habilitá el permiso **"Instalar aplicaciones desconocidas"** para esa fuente.
5. Una vez instalada, abrí la aplicación y concedé el **permiso de cámara** cuando te lo solicite para poder escanear los códigos QR de los stands y objetos físicos.
